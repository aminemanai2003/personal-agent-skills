# Compact Design Brief

Before a substantial interface build, capture:

- Product and target user.
- First-screen job and primary repeated workflow.
- Existing design tokens and patterns that must remain.
- Required information hierarchy and density.
- Required loading, empty, error, access, and success states.
- Supported viewports, input methods, and accessibility constraints.
- Palette roles, typography roles, layout tracks, and one signature choice.
- What would make this design look generic for the subject.
