# Severity Guide

- Critical: likely data loss, severe security exposure, or system-wide outage with no practical guard.
- High: reachable correctness, security, or compatibility defect that blocks an important workflow.
- Medium: material defect with narrower impact, workaround, or lower likelihood.
- Low: real but limited maintainability or behavior risk; exclude pure preference.

Severity is not effort. A one-line fix can be critical, and a large refactor can be low priority.
