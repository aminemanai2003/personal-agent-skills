# Application Workflow

## Search Contract

Record before collecting roles:

- primary and fallback role families;
- seniority and internship or employment type;
- allowed locations and work arrangements;
- work authorization, enrollment, graduation, and start-date facts;
- hard compensation or relocation constraints when applicable;
- strongest verified evidence and important gaps;
- weekly time budget and review cadence.

## Opportunity Record

| Field | Required content |
| --- | --- |
| Source | Employer URL or authoritative source plus access date |
| Eligibility | Confirmed, unresolved, or unmet with the exact reason |
| Requirements | Must-have and preferred capabilities separated |
| Evidence | Candidate artifact or experience for each important capability |
| Constraints | Location, schedule, authorization, language, compensation, deadline |
| Effort | Expected tailoring, assessment, referral, or portfolio work |
| State | Found, evaluating, preparing, ready, submitted, interviewing, closed |
| Next action | Concrete action, owner, and date |

## Transparent Prioritization

Evaluate separate dimensions rather than hiding them in one number:

- eligibility and hard-constraint status;
- evidence coverage for must-have capabilities;
- role and company value to the candidate;
- stretch distance and credible bridge;
- deadline urgency;
- application effort and opportunity cost;
- confidence in the posting facts.

Use tiers such as `priority`, `credible stretch`, `exploratory`, and `do not pursue`. Include one sentence of reasoning and unresolved facts for every tier decision.

## Tailoring Package

1. Select two or three proof points that address the role's highest-value requirements.
2. Tailor the resume without changing the factual base.
3. Ensure public links support the claims a reviewer is likely to inspect.
4. Answer application questions directly with verified evidence and within stated limits.
5. Name files and versions so the submitted package can be reconstructed later.

## Outreach Pattern

A useful message normally contains:

- why this specific person, team, company, or role is relevant;
- one concise evidence signal;
- a small, clear request;
- no invented familiarity, urgency, praise, or referral claim.

Follow up only when appropriate for the channel and timeline. One useful follow-up is better than repeated nudges with no new information.
