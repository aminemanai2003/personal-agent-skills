# ADR 0002: Private Repository During V1

Status: accepted

## Decision

Create `aminemanai2003/personal-agent-skills` as a private GitHub repository during initial development.

## Rationale

The repository contains personal operating preferences and potentially private project patterns. A private default avoids accidental disclosure while the profile and examples are still being refined.

## Consequences

External principles remain cited and original. A later public release would require a separate license, secret scan, and privacy review.
