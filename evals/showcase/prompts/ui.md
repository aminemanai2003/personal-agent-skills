# UI benchmark prompt

Build a complete, responsive claims-reserving review dashboard for actuarial analysts.

Create a self-contained website using only `index.html`, `styles.css`, and `app.js`. Do not use external libraries, fonts, images, CDNs, or network requests. The result must work through a local static server.

Product name: Northstar Reserve Review.

The first screen must support a reserve-review workflow and include:

- Portfolio period: Q2 2026.
- Total selected reserve: $148.2m; change from prior review: +3.7%.
- Four lines of business: Motor, Property, Liability, and Marine.
- Model comparison for Chain Ladder, Bornhuetter-Ferguson, and Cape Cod.
- Review queue with three items: Motor bodily injury deterioration, Property large-loss adjustment, and Marine sparse development history.
- Development-triangle freshness and data-quality status.
- A line-of-business filter and a control for switching between central estimate and uncertainty view.
- Meaningful loading, empty, and warning states that can be demonstrated from controls in the page.

Use realistic domain vocabulary and values. Build functional interactions, not a static mockup. Make the layout usable at 1440x960 and 390x844.

Use any relevant project-local skills if available. Work directly in the current directory. When finished, verify the files and report only a short completion summary.
