# Writing benchmark prompt

Write a 260-320 word passage for experienced actuarial and machine-learning practitioners explaining why a single composite score can mislead model selection in a claims-reserving benchmark.

The passage must address these facts:

- Predictive accuracy, calibration, stability across accident years, and computational cost answer different questions.
- A weighted composite embeds value judgments in its weights.
- Two models can receive the same total score while having materially different risk profiles.
- The preferred model depends on the intended decision and tolerance for reserve volatility.

Write continuous prose with no heading, bullets, quotation, or invented citation. Do not mention this prompt, AI, or the writing process. Use any relevant project-local skills if available. Return only the passage.
