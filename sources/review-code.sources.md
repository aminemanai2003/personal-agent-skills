# Review Code Sources

Inspired by:

- Addy Osmani's code-review-and-quality workflow.
- Superpowers' receiving/requesting code review and systematic debugging skills.
- OWASP boundary-focused security guidance.
- Codex review conventions that prioritize findings and file/line evidence.

Adapted principles:

- Understand intent and tests before implementation details.
- Report concrete reachable defects, ordered by severity.
- Recommend root-cause remedies rather than vague cleanup.

Personal additions:

- Strict separation of patch regressions from pre-existing issues.
- Explicit no-findings and residual-risk behavior.

Original implementation:

- The review sequence, severity guide, constraints, and examples are original.
