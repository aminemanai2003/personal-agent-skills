# GitHub Workflow Sources

Inspired by:

- GitHub's awesome-copilot repository for reusable repository workflows.
- Conventional Commits for scoped, searchable history.
- OpenAI Codex GitHub skills for PR orientation, review threads, CI logs, and publication boundaries.
- Amine's preference for small meaningful commits and direct PR resolution.

Adapted principles:

- Inspect live PR, review, and check state before acting.
- Tie thread resolution and completion to evidence.
- Keep history and PR scope reviewable.

Personal additions:

- Explicit external-action authorization boundary.
- Credential handling and stale-state checks.

Original implementation:

- The end-to-end workflow, constraints, and examples are original.
