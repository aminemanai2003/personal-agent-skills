# Definition Of Done Sources

Inspired by:

- `PM.md` definition-of-done and stopping-condition sections.
- Superpowers' verification-before-completion workflow.
- Testing Library's user-observable testing philosophy.
- Playwright and axe-core as complementary UI verification tools.

Adapted principles:

- Evidence must cover the claimed scope.
- Verification should scale with risk and changed contracts.
- Automated checks complement, rather than replace, direct inspection.

Personal additions:

- Explicit quantitative/research completion criteria.
- Strong final-diff and artifact review.
