# Anti-Slop Sources

Inspired by:

- `PM.md` sections on UI, code, content, and agent slop.
- Anthropic's frontend-design emphasis on subject-specific choices and self-critique.
- Superpowers' verification-before-completion workflow.
- Existing Amine projects that document limitations and avoid arbitrary rankings.

Adapted principles:

- Specificity must come from the task and domain.
- Verification is part of quality, not a closing ritual.
- Remove unnecessary moving parts before adding instructions.

Personal additions:

- A cross-domain test for whether every prominent element earns its place.
- Explicit protection against arbitrary quantitative composites.

Original implementation:

- The workflow, constraints, verification test, and examples are original.
