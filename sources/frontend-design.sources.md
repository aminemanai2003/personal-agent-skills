# Frontend Design Sources

Inspired by:

- Anthropic's frontend-design skill and its subject-grounded design process.
- Vercel web-interface guidelines and web-design skill structure.
- Accessibility principles supported by axe-core and browser testing practices.
- Amine's observed preference for quiet, dense, task-focused interfaces.

Adapted principles:

- Derive visual decisions from the product's subject and workflow.
- Use a compact design direction before implementation.
- Verify through rendered desktop and mobile inspection.

Personal additions:

- Strong operational-tool defaults and explicit anti-card-stacking rules.
- Stable dimensions and complete interaction states as design requirements.

Original implementation:

- The workflow, control mapping, constraints, brief, and examples are original.
