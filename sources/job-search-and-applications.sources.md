# Job Search And Applications Sources

Public skill comparison:

- `onewave-ai/claude-skills`, job application workflow, commit `82859c0ebaff803889be6ca2efa0834ba8787773` (MIT). Useful concepts: structured job analysis, application preparation, and reusable workflow stages.
- `Paramchoudhary/ResumeSkills`, commit `74ae19e7c62b0516d1c298328e5544976c12da5d` (MIT). Useful concepts: requirement mapping, application tailoring, recruiter communication, and career-material consistency.
- `github/awesome-copilot`, technical job-search materials inspected at commit `406c31f848e641e9ccb33277cb03b51b015c27c7` (MIT). Useful concepts: evidence-led technical job search and portfolio alignment.

Authoritative-source rule:

- Treat the employer's current careers page or job posting as primary for eligibility, requirements, location, deadline, and application instructions. Search indexes and aggregators are discovery sources, not final authority.

Adaptation boundary:

- Rewrote all workflow, tables, prioritization dimensions, and examples in original language; no third-party skill body was copied.
- Rejected mass-application defaults, opaque universal match scores, generic outreach templates, and automatic external actions.
- Added source freshness, explicit authorization boundaries, internship eligibility, application versioning, and unknown-state handling.

Original implementation:

- Search contract, multi-dimensional priority tiers, opportunity record, external-action confirmation, and response-pattern caution are original.
